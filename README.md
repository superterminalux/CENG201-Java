# 📚 CENG201 - Java Programming Coursework

This repository contains the weekly laboratory exercises and the project for the **CENG201** course.

## 🗂️ Repository Structure

To prevent dependency conflicts between the project and the laboratory assignments, they are structured as two completely independent directories:

*   **`📁 Labs/`** : Weekly laboratory exercises and coding practices. Each week is categorized within its own `package`.
*   **`📁 Project/`** : The final term project. This is the main working directory featuring its own architecture, source files, and independent business logic.

## 🛠️ Technologies & Tools
*   **Language:** Java 
*   **IDE:** IntelliJ IDEA
*   **Version Control:** Git & GitHub
